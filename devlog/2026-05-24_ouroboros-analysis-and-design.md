# 우로보로스 분석 & Antigravity용 재구현 설계

> 📅 2026-05-24 (토) 23:24 KST

---

## 🗺️ 어떤 상황이었나

jdy_agy 프로젝트를 시작하면서 개발 워크플로우를 체계화할 도구가 필요했다. 오픈소스 [Ouroboros](https://github.com/Q00/ouroboros)를 발견하고, 이것을 Antigravity CLI 환경에 맞게 재설계해서 사용하고 싶었다.

---

## 🎯 무엇을 원했나

- 오리지널 오픈소스의 기능을 파악하고 Antigravity CLI에서 바로 쓸 수 있는 형태로 재구현
- MCP 없이 프로젝트 파일 기반으로 동작하도록 구성
- 서브에이전트를 병렬로 띄워 빠르게 작업하고 결과 보고받는 방식

추가로 중간에 요구사항이 확장됐다: **어느 세션, 어느 컴퓨터에서 작업해도 동일하게 동작하는 멀티머신 이식성** 확보.

---

## 💬 어떤 요청을 했나

> "https://github.com/Q00/ouroboros 의 기능을 파악하고 antigravity cli에서 사용할 수 있는 방법으로 최적화해서 구현해. 서브에이전트를 적절히 분출해서 병렬로 빠르게 작업하고 결과 보고해. mcp 사용하지 말고 프로젝트 파일에서 작동할 수 있도록 구성해."

이후 결과를 확인하며 추가 요청이 이어졌다:

> "여기서 이루어지는 모든 개발은 프로젝트 폴더에 종속해. user 폴더에 종속하지 말고. 어느 세션, 어느 컴퓨터로 작업해도 동일하게 작동하도록 규칙 생성하고 다 준비해."

> "다른 컴퓨터에서 동일하게 작동하기 위해 user 폴더에 종속하는 요소가 뭐야?"

---

## ✅ 어떤 결과물이 나왔는가

- ✅ `AGENTS.md` — AI 세션 바인딩 규칙 (멀티머신 이식성 규칙 포함)
- ✅ `requirements.txt` — Python 의존성
- ✅ `.env.example` — 환경변수 템플릿
- ✅ `setup.py` — 자동 환경 구성 유틸리티 (venv 초기화 + 스킬 배포 포함)
- ✅ `agyd` / `agyd.bat` / `agyd.ps1` — 플랫폼별 로컬 셸 단축 명령어
- ✅ `ouroboros/` 패키지 구조 설계 완료 (cli, config, seed, interview, execution, evaluation, resilience)

## 💡 느낀 점 / 배운 점

GitHub 레포를 직접 읽고 기능을 파악한 뒤 Antigravity 환경에 맞게 재설계하는 흐름이 빨랐다. "어느 컴퓨터에서도 동일하게 동작해야 한다"는 요구가 중간에 추가됐는데, 이것이 `AGENTS.md`와 `setup.py`라는 핵심 결과물로 이어진 부분이 흥미로웠다.
