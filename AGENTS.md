# AGENTS.md — Binding AI Session Rules

This file defines **mandatory rules** for any AI agent, session, or computer working on this project.
All AI agents (Antigravity CLI, Claude, Gemini, Codex, etc.) MUST read and follow these rules at session start.

---

## RULE 1: Project Folder Is the Single Source of Truth

**ALL development artifacts MUST be stored inside this project folder:**
```
C:\Users\user\Desktop\jdy_agy\
```

**NEVER store project files in user-specific or machine-specific paths such as:**
- `C:\Users\user\.gemini\...`
- `C:\Users\user\.antigravity-cli\...`
- `%APPDATA%\...`
- `/tmp/...`
- `~/.config/...`
- Any path containing a username or machine-specific directory

**Why:** These paths differ between sessions and computers. The project folder is tracked by git and portable across all environments.

---

## RULE 2: Artifacts and Plans Go in `.ai-workspace/`

When an AI agent needs to store implementation plans, task checklists, research notes, or walkthroughs as part of its work, it MUST place them in:
```
C:\Users\user\Desktop\jdy_agy\.ai-workspace\
```

**Subdirectory structure:**
```
.ai-workspace/
  plans/          # Implementation plans and architecture docs
  tasks/          # Task checklists and progress trackers
  walkthroughs/   # Post-completion summaries
  research/       # Research notes and analysis
  scratch/        # Temporary working files
```

**NOT in:** `~/.gemini/antigravity-cli/brain/...` or any user-level path.

---

## RULE 3: Configuration Is Code

All project-wide configuration must be in this project folder:
- `requirements.txt` — Python dependencies
- `.env.example` — Environment variable template (never `.env` with actual values)
- `AGENTS.md` — This file: AI session rules
- `ouroboros_seed.yaml` — Active specification (auto-generated by Ouroboros interview)
- `ouroboros_plan.md` — Active execution plan (auto-generated by Ouroboros planner)

---

## RULE 4: Ouroboros Lite Workflow

This project uses **Ouroboros Lite** for specification-first development. Always follow the loop:

```
interview → plan → [code] → evaluate → status
```

Commands (run from project root):
```bash
python run_ouroboros.py interview   # Phase 0: Socratic requirements interview
python run_ouroboros.py plan        # Phase 2: Kahn's topological sort planning
python run_ouroboros.py evaluate    # Phase 4: Mechanical + Semantic verification
python run_ouroboros.py status      # Phase 3: Stagnation detection + Persona advice
```

---

## RULE 5: Session Handoff Protocol

When starting a new session, the agent MUST:
1. Read this `AGENTS.md` file first
2. Read `ouroboros_seed.yaml` if it exists (current active specification)
3. Read `.ai-workspace/tasks/` for any in-progress task checklists
4. Read `ouroboros_plan.md` for the current execution plan
5. Only then begin working

---

## RULE 6: Git Hygiene

- All code changes must be committed with meaningful messages
- Never commit `.env` files (only `.env.example`)
- The `.ai-workspace/scratch/` directory is gitignored
- All other `.ai-workspace/` content SHOULD be committed for session continuity
